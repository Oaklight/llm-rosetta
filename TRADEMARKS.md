# LLM-Rosetta trademark and naming policy

The "LLM-Rosetta" name and the stone mark in `design/logo/` identify this
project and its maintainers. The source code is MIT licensed. MIT grants
copyright permissions only, so it does not grant any right to use the name or
the marks, and the mark files carry their own terms in
[`design/logo/LICENSE`](design/logo/LICENSE).

## Allowed uses

You may use the name and the mark to refer to the project truthfully:

- saying that your project integrates with LLM-Rosetta, or that a format is
  supported by it
- tutorials, reviews, talks and documentation about LLM-Rosetta
- screenshots, package metadata and links to the repository or the docs

## Uses that need permission

Ask first before using the branding for:

- a product, company, domain, app or hosted service with a name that could be
  confused with LLM-Rosetta
- a paid service or marketing that implies endorsement by Oaklight or the
  maintainers
- modified marks that stay confusingly similar to the official mark
- merchandise

## Forks and modified versions

The MIT license lets you fork and modify the software. Distribute a modified
version under its own name and logo, and keep the relationship visible:

> Based on LLM-Rosetta, an MIT-licensed API format converter and gateway.

Do not present a fork, hosted service or repackaged distribution as the
official LLM-Rosetta project.
