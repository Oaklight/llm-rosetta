提供方抽屉：Basic / Auth

Basic 只放身份、认证方式摘要和模型类型；选中类型的端点配置按 master 的卡片展开。Auth 放凭据本身。点一行提供方打开抽屉。

  • 勾选 / 取消模型类型，端点卡片随之出现或消失。
  • 端点卡片沿用 master：左侧色条、已启用开关、自动禁用提示。
  • Basic 的认证方式只读，点任意模式跳到 Auth 修改。
  • 「ALCF Sophia」演示端点自动禁用与凭据失败两种状态；提供方数据取自 prod 配置。
