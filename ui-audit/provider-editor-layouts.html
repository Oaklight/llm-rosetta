提供方抽屉布局

模型类型设置（能力、端点）和凭据设置挤在同一个抽屉里。下面三种分法共用同一份内容，点顶部切换，抽屉里的一切都能点。

提供方凭据来源状态

方案 A · 凭据折叠

一个长页，凭据收进折叠区，标题行给状态摘要。

  • 改动最小，不引入页签
  • 页仍然长；展开会推走后面的端点设置
  • 摘要行必须自带状态，否则凭据问题看不见
适合：凭据很少改、但需要偶尔看一眼

方案 B · 两个子页

抽屉分「提供方与模型类型」和「凭据」两页，保存按钮固定在底部。

  • 每页都短，任务边界清楚
  • 凭据问题藏在页签后面
  • 需要给页签加状态点，否则容易漏
适合：端点配置很长、经常在改的情况

方案 C · 子页 + 状态条

在 B 上加一条常驻的凭据状态，页签带异常点，出问题自动打开凭据页。

  • 兼顾短页面与可见状态
  • 状态条只放结论，不放大段配置
  • 比 B 多一行常驻高度
推荐：编辑频率和可见性都照顾到
